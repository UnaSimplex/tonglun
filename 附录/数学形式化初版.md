## 一、核心变量定义

| 变量 | 定义 | 单位 | 当前可测？ |
|------|------|------|------|
| r(t) | 光锥半径，t=燃爆启动至今的时间 | m | 是（可观测宇宙半径~4.4×10²⁶ m） |
| t | 光锥内部时间（从燃爆算起） | s | 是（宇宙年龄≈4.35×10¹⁷ s ≈138亿年） |

## 二、基本方程（第一版）

### 方程1：光锥膨胀

```
dr/dt = c                                  (1)
初始条件：r(0) = 0
```

释义：光锥以光速向外膨胀。这是燃爆=光子前沿的定义。

### 方程2：内核层质量守恒

```
∂ρ_inner/∂t = -k₁·ρ_inner + k₂·Φ(t)/V(t)  (2)
V(t) = (4/3)πr³                           （光锥体积）
```

释义：内核层质量密度变化 = 自然衰变（第一项）+ 锁死点吞吐注入（第二项）。
- 早期（t<38万年）：光子能量>1.022MeV → k₂大 → 造物活跃
- 中后期：光子能量<阈值 → k₂≈0 → 质量仅自然衰变

### 方程3：光锥层能量密度

```
ρ_light(r,t) = ρ_CMB(r,t) + ρ_star(r,t) + ρ_pump(r,t)  (3)
ρ_pump(r,t) = Φ(t) / (4πr²c)                           （锁死点直接泵出）
ρ_star(r,t) = ∫ε_star(M,t) dM                          （恒星二次供能积分）
```

### 方程4：总能量守恒（三层统一）

```
d/dt [∫ρ_outer dV_outer + ∫ρ_light dV_light + ∫ρ_inner dV_inner] = 0  (4)
```

释义：三层总能量守恒。外层混沌无限→ρ_outer的变化不影响总量。但中间层+内核层能量变化必须等于吞吐净流量。

## 三、关键推论的数学表达

### 推论1：暗能量=吞吐功率

观测到的宇宙加速膨胀 ↔ 方程(2)中的Φ(t)项不为零：
```
如果Φ(t) > 0，则 d²r/dt² > 0（膨胀加速）
观测值：d²r/dt² ≈ 10⁻¹⁰ m/s²（从ΛCDM反推）
```

### 推论2：层级问题=密度瀑布的等效落差

```
普朗克能量 / 质子质量 = √(Φ_0 / ε_QCD) ≈ 10¹⁹
Φ_0 = 锁死点吞吐的"单次呼吸"能量（≈ 普朗克能量 ≈ 1.22×10¹⁹ GeV）
ε_QCD = QCD禁闭能标（≈ 200 MeV → 质子质量≈1 GeV = 3个夸克的结合能）
```

### 推论3：CMB冷斑=光锥碰撞的"降温区"

```
ΔT/T|_冷斑 = -β·A_collision / A_surface
β = 碰撞冷却系数（未知）
A_collision = 碰撞接触面积
A_surface = 观测天区面积
```

## 四、可计算的检验量

### 检验1：光锥内部的质量-光比演化曲线

模拟方程(2)从t=0到t=138亿年→生成ρ_inner(r,t_现在)→与SDSS/2dF星系巡天的大尺度质量分布对比。

**通过标准**：模拟结果应再现观测到的"星系团+巨洞"的不均匀结构——核心稠密、外围虚空。

### 检验2：α随时间演化曲线

如果锁死点吞吐频率在早期略低→α早期略小：
```
α(t_早期) / α(t_现在) = 1 - η·(1 - e^(-t/τ))
η = 吞吐频率稳定化参数（未知，需拟合）
τ = 频率稳定时间（≈ 普朗克时间? ≈ 10⁻⁴³ s 或更长?）
```

### 检验3：巨洞椭率与碰撞方向的关联

```
e(空洞) = 1 - b/a
a = 长轴，b = 短轴
预测：如果巨洞=碰撞伤疤 → e>0 → 长轴方向⊥碰撞方向
检验：用SDSS/DESI空洞目录计算e分布 → 是否系统性>0 → 方向是否随机
```

## 五、当前形式化的局限

| 局限 | 严重程度 | 解决路径 |
|------|------|------|
| k₁未测定（质子衰变） | 中 | 不影响短期模拟（k₁极小） |
| k₂(r,t)完整形式未知 | 高 | 需要光子-物质转换的精确截面 |
| Φ(t)完整形式未知 | 高 | 需要从锁死点群论模型中推导 |
| ρ_outer无操作定义 | 高 | 短期内无法解决——视作自由参数 |
| V_outer无限→能量守恒方程(4)无约束力 | 中 | 改用中间层+内核层局部能量守恒 |
